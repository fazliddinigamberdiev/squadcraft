SquadCraft — ISE4133 Software Engineering · Team: Rakhmatullaev Umid, Abdullaev Umrbek, Igamberdiev Fazliddin.
Architecture: this page is a thin client. All data and all rules (depth, thin-depth, upgrades, future-proof, free agents, offload) live in a Supabase PostgreSQL database and run as SQL functions; see db/schema.sql. Data: players, positions, ages, nationalities, contracts and market values come from Transfermarkt via the open transfermarkt-datasets project (snapshot 6 July 2026); free agents from transfertracker.ai (22 Oct 2026) and news reports (2–4 Sep 2026). Squads of the 14 newly promoted clubs are simulated (made-up players). Est. ratings, potential, style attributes and wages are SquadCraft model estimates, not official figures.
